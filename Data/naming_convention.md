# Специфікація даних та правила кодування насаджень (Garden Schema)

## 1. Структура ідентифікатора (tree_id)
Формула коду: `[ДІЛЯНКА]-[ЗОНА/РЯД].M[ВІДСТАНЬ]`

### Префікси ділянок:
* `M` (**Main**) — Основна ділянка.
* `H` (**House**) — Ділянка біля хати / за хатою.

### Зони та ряди:
| Код зони | Ділянка | Опис / Призначення |
| :--- | :--- | :--- |
| `H-H` | House | Безпосередньо за хатою |
| `H-G` | House | Смуга перед городом (шовковиця, фундуки, сливи) |
| `H-R1`| House | 1-й ряд: Ягідники (малина, смородина, аґрус, жимолость) |
| `H-R2`| House | 2-й ряд: Великі дерева та медоноси (горіхи, еводія, каштани) |
| `M-R1`–`M-R7` | Main | Ряди 1–7 основної ділянки |

### Позиція (відстань):
* Позначається через `.M` + відстань у метрах від базової точки відліку (наприклад: `M02`, `M14`, `M35`).
* Якщо посадка не на цілому метрі: дозволено десятковий роздільник `.` (наприклад: `M12.5`).

## 2. Довідник полів файлу `trees.csv`

1. **`tree_id`** *(рядок, обов'язкове, унікальне)*: Відповідає шаблону кодування вище.
2. **`plot`** *(рядок, обов'язкове)*: Тільки значення `main` або `house`.
3. **`row`** *(рядок/число, обов'язкове)*: `1`..`7`, `перед городом`, `біля хати`.
4. **`distance_m`** *(число >= 0, обов'язкове)*: Відстань від початку ряду в метрах.
5. **`crop`** *(рядок, обов'язкове)*: Культура українською (наприклад: `Яблуня`, `Фундук`, `Жимолость`).
6. **`variety`** *(рядок)*: Сорт.
7. **`rootstock`** *(рядок)*: Підщепа (наприклад: `ММ-106`, `ВА-29`, `алича`, `Антипка`).
8. **`planted_year`** *(ціле число YYYY)*: Рік висадки (наприклад: `2024`).
9. **`status`** *(enum, обов'язкове)*: Дозволені лише 4 стани:
   * `прижилося`
   * `посаджено` (для посадок поточного сезону)
   * `сумнівно` (потребує спостереження)
   * `засохло` (вибуло / підлягає видаленню чи заміні)
10. **`notes`** *(рядок)*: Додаткові коментарі (запилювач, особливості обрізки, дата всихання).
